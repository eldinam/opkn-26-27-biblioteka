# OPKN · Biblioteka

Projekat sa vježbi iz predmeta **Odabrana poglavlja kompjuterskih nauka**, PMF Sarajevo, 2026/2027.
Kroz semestar gradimo web aplikaciju za biblioteku u Node.js-u sa Express-om i EJS-om.

## Pokretanje

```bash
npm install
npm start
```

Aplikacija radi na http://localhost:3000

## Stanje po sedmicama

Svaka sedmica ima dva taga:

| Tag | Šta sadrži |
|---|---|
| `vNN-cas` | kod sa termina NN (ono što smo radili zajedno) |
| `vNN` | kod sa rješenjem zadatka, polazna tačka za sedmicu NN+1 |

Spisak svih tagova: kartica **Tags** na GitHub-u.

## Ako vam projekat ne radi ili ste propustili termin

1. Na GitHub-u: **Tags**, izaberite tag prethodne sedmice (npr. `v05`), **Download ZIP**
2. Raspakujte, otvorite folder u VS Code-u
3. U terminalu: `npm install`, pa `npm start`

Sa Git-om: `git clone <link>`, pa `git switch -c moj-rad v05`
