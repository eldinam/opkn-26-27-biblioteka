PRIJE NODE-A

Server u PHP-u, Javi, C#-u, Ruby-ju ili Pythonu. JavaScript samo u browseru.

Zato podnosi mnogo istovremenih konekcija.

npm

Paketi i package.json

package.json
{
  "name": "biblioteka",
  "scripts": {
    "start": "node ./bin/www"
  },
  "dependencies": {
    "express": "~4.16.1",
    "ejs": "~2.6.1"
  }
}
> npm install   # preuzmi sve sa spiska
> npm start     # pokreni skriptu "start"
  • dependencies: spisak paketa koje projekat koristi
  • scripts: prečice za komande
  • node_modules/: preuzeti paketi, ne šalje se nikome

Pokretanje

Od nule do localhost:3000

> npx express-generator --view=ejs biblioteka
> cd biblioteka
> npm install
> npm start

GET / 200 9.412 ms - 207
GET /stylesheets/style.css 200
Generator koristi stare verzije paketa, pa npm install prijavi ranjivosti. Ažuriramo u V_02.
Logove ispisuje morgan: metoda, putanja, status, vrijeme. Ctrl + C gasi server.

Instalacija alata: uputstvo_instalacija.md

Struktura

biblioteka/
├── bin/www          kreira HTTP server
├── app.js           middleware i rute
├── package.json
├── public/          statički fajlovi
│   └── stylesheets/style.css
├── routes/
│   ├── index.js
│   └── users.js
└── views/
    ├── index.ejs
    └── error.ejs

Danas mijenjamo:

  • routes/index.js
  • views/index.ejs
  • public/stylesheets/style.css

app.js i bin/www detaljno u V_02.

Express i EJS

Ruta poziva šablon

routes/index.js
router.get('/', (req, res) => {
  res.render('index', {
    title: 'Biblioteka'
  });
});

Express: metoda + putanja → funkcija (req, res).

views/index.ejs
<h1><%= title %></h1>
HTML koji ode klijentu
<h1>Biblioteka</h1>

EJS: HTML sa JavaScript izrazima, izvršava se na serveru.
